## 導線（ファネル）

```
Threads プロフィール
   ↓
このLP
   ↓
LINE公式（友だち追加・無料ミニ鑑定）
   ↓
鑑定結果
   ↓
「もっと詳しく知りたい」
   ↓
MOSH（決済ページ）
   ↓
本鑑定
```

LP上の全CTA（ヘッダー・ヒーロー・メニューの「選択する」）は `#cta` へのアンカーで、ページ最下部の
LINE友だち追加ボタンに集約する設計です。友だち追加URLは `https://lin.ee/8KUu7Op`（推奨リンク）を設定済みです。

決済プラットフォームには **MOSH** を採用しています。理由：
- Stripe・Squareは規約上「占い・サイキックサービス」を制限業種としているため、直接契約はリスクがある
- MOSHは占いサービスの販売実績があり、特商法の「事業者の所在地・連絡先」を非公開設定できる（非公開時はMOSH株式会社の情報が表示される）
- 本人情報はMOSHに正確に登録した上で、購入者向け表示のみ非公開にする、という正規の運用

本鑑定の購入自体はMOSHの決済ページで完結させ、このLPには決済機能を持たせない設計です。

MOSH公開ページ: https://mosh.jp/yuibi-rin/profile
（プロフィール・キャッチコピー・LINEリンク・3商品とも設定済み — `02_商品/mosh-menu-copy.md` 参照）

## 確定済みの内容

- 料金：一灯リーディング ¥2,980、結縁リーディング ¥5,980（おすすめ。販売実績が出るまで「人気」とは表記しない）、月灯り総合 ¥9,800
- 提供形式：すべて**鑑定書（テキスト）でのお届け**。対面・ビデオ通話・リアルタイムチャットでのセッションは行わない
- 納品目安：お申し込みから**1週間以内**
- お客様の声：実績がまだ無いため、セクション自体を削除（今後、実際の声が集まったら追加を検討）
- 決済方法：クレジットカード決済（MOSH経由）。`tokushoho.html` とFAQに反映済み
- 特定商取引法に基づく表記（`tokushoho.html`）：販売事業者「ツギメ」、返金条件（鑑定書作成着手前は全額返金／着手後は返金不可）を記載済み
- MOSH商品ページ用コピー：`02_商品/mosh-menu-copy.md` に3メニュー分を用意（鑑定書形式・1週間納品を反映済み、MOSHへの登録時にそのまま利用可能）
- 鑑定書PDFテンプレート：`02_商品/鑑定書テンプレート.docx`（表紙＋8セクション構成、毎回コピーして使い回す。`02_商品/鑑定書テンプレート_preview.pdf` で内容確認可能）
- LINE購入後メッセージ：`04_セールス/line-purchase-message.md` に3メニュー分の①受付（ヒアリング項目付き）②受領確認③納品メッセージを用意
- 鑑定書サンプルページ：`sample.html`（架空の人物名で鑑定書の一部を抜粋表示。LPのメニューセクションから「鑑定書のサンプルを見る」でリンク）
- LP最終チェック：全ページ・アセットの配信確認、内部リンク・アンカーの整合性、CTA導線（ヘッダー→LINE）、モバイルメニューのJS動作を確認済み（詳細は本ファイル更新時の会話履歴を参照）
- Threads固定投稿・販売導線：`03_マーケ素材/投稿/threads-posts.md` に固定投稿3本（①結灯凛とは？②無料ミニ鑑定について③有料鑑定について）と、通常投稿からの誘導フレーズ・ハッシュタグ案を用意
- **LPのホスティング**：GitHub Pagesで公開済み（https://yuibi-rin.github.io/yuibi/）。実サイトファイル（`index.html`/`tokushoho.html`/`sample.html`/`css`/`js`/`images`/`README.md`）のみをリポジトリにpush、内部運用ドキュメント（MOSH用コピー・LINEメッセージ・鑑定書テンプレート・Threads投稿文面）は `.gitignore` で除外しローカルのみ保持
- **MOSHへの登録・公開**：3商品（一灯リーディング¥2,980／結縁リーディング¥5,980／月灯り総合¥9,800）を「決済単体での利用」テンプレートで作成し、`02_商品/mosh-menu-copy.md`の文面を反映。事業者情報（本人確認情報）をMOSHに登録後、プラン・商品ともに**一般公開**に設定済み。実際にクレジットカードで購入可能な状態です

## フォルダ構成について

`01_会社情報`〜`99_アーカイブ` は、このプロジェクトを「AIマーケ会社」として運用するための共通テンプレート構成です（`CLAUDE.md` 参照）。LPの内部運用ドキュメント（MOSH用コピー・LINEメッセージ・鑑定書テンプレート・Threads投稿文面・サムネイル画像）はこの構成の該当フォルダに整理しています。デプロイされるサイト本体（`index.html`/`tokushoho.html`/`sample.html`/`css`/`js`/`images`）は、GitHub Pagesの配信元設定（リポジトリのルート）に合わせて、これまで通りリポジトリのルート直下に置いたままにしています。
